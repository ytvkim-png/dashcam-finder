# Dashcam Finder

Find a moment in recorded video, then check it in the original footage.

Dashcam Finder is a Windows app for searching candidate scenes in supported CCTV exports, security-camera recordings and dashcam footage. Describe visible objects or clothing in English, compare a face-free reference crop, or explore vehicle-model candidates. Video analysis runs locally on your PC.

[Download from Microsoft Store](https://apps.microsoft.com/detail/9PG5XX8ZHZMD) · [Product information](https://today-tip.com/video-search-preview/) · [Step-by-step walkthrough](https://today-tip.com/find-scenes-cctv-video-dashcam-finder/)

## What you can do

- Search a prepared recording using an English description of a visible scene.
- Compare a face-free crop of clothing, an object or a vehicle with candidate scenes.
- Explore vehicle-model candidates for closer manual comparison.
- Select a suggested timestamp and review the original recording in context.
- Save a project and export results using the app controls.

## Your first search

1. Install the app from Microsoft Store and use the trial to check your PC.
2. Sign in, open a supported recording and let analysis finish. Preparation, analysis and query time are separate stages.
3. Enter an English description such as `a motorcycle` or `a person in a dark jacket and blue jeans`.
4. Select a candidate timestamp and play the original video to check what is actually visible. Preserve the original recording.

## Before you buy

Use the trial with your own footage. The app requires Windows x64, a compatible OpenVINO GPU, Intel QSV decoding and supported unrotated 8-bit constant-frame-rate H.264 MP4/MOV recordings. Some recorder exports need conversion. Sign-in and licensing need internet. The current public Store interface is English.

Results are candidates for human review. Small, blurred, hidden or very brief events can be missed; vehicle-model candidates require visual checking. Verify the original video before drawing conclusions. Use recordings you are authorized to review.
